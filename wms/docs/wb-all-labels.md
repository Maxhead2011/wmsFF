# WB FBS: скачать все ШК

Опубликовано PR919, 08.11.2026.

Для заказа, группы поставки и выбранных заказов добавлено действие «Скачать все ШК».
Один PDF содержит доступные коды СЦ, затем ПВЗ, затем существующие этикетки
товара/заказа парами для немаркированных товаров. Для маркированных товаров
сохраняются прежние ограничения печати. Обычная «Скачать ШК» не изменена.

Если код ещё не доступен, остальные страницы скачиваются, а интерфейс показывает
недостающие части. Код поставки включается один раз на кабинет/поставку.
Неизвестные/чужие выбранные заказы и ошибки доступа не превращаются в частичный
успех. При 429/ошибке сервиса скачивание не запускает автоматические повторы.
При ошибке доступности группы этикеток проверяются меньшие группы, чтобы сохранить
доступные пары. Пустой PDF не скачивается.

Это действие не создаёт грузоместа, не передаёт поставку и не списывает метры.
Коды СЦ/ПВЗ подчиняются прежним правилам направления и состояния поставки.

Изменены: FbsPanel.tsx, lib/api.ts; marketplace-connections controller/service;
новый wb-all-labels.ts; реестр administration-internal-api.service.ts.
Runtime: точечный API4/web3 overlay от PR916/917, sourceParityVerified=false.
Проданная ВМС, APK258, агент печати и конфигурация не меняются.

Проверки: wb-all-labels.spec.ts (8), compiled runtime (6), browser (6),
общие API/web тесты, baseline (8), оформление (24), шапка заявок (12),
изолированный запуск всего API с тестовой PostgreSQL.
Физический принтер и реальная лента выбранной поставки отдельно не проверены.
Полный API TypeScript сохраняет прежние две ошибки nullable skuId в Yandex FBY;
новых ошибок типов нет. DB integration suites требуют отдельной базы и исключены.

Скрипты выпуска: scripts/releases/wb-all-labels-20261108/.


## Печать всей ленты (подготовлено 08.11.2026)

«Печатать все ШК» доступно для заказа, поставки и выбранных заказов WB.
Диалог показывает число страниц, недостающие коды и доступные станции с именем
принтера. Нужен доступ к печати и агент с форматом 58 × 40 мм.
Вся лента отправляется одним заданием существующей серии. Повтор запроса после
неподтверждённого ответа использует тот же UUID. Закрытие диалога до подтверждения
ничего не печатает. Недоступный агент не мешает скачать PDF.

Ограничения: PDF до 6 МБ, до 500 страниц и 60 млн пикселей; слишком большая лента
отклоняется до очереди с предложением уменьшить выбор. Реальная печать не выполнялась.

Замеры на сохранённом выборе заказов с реальными ответами WB: №2817 — 0,76 с,
№2818 — 0,92 с, №2781 — 0,61 с на получение/сборку PDF. Это не полное время
загрузки списка и передачи файла браузеру. Подготовка пяти страниц агенту — 0,28 с.
Проверки: API4583/web613 (9/2 skipped; DB integration исключены), новый renderer2,
service6, web1; native dialog browser4; compiled handler7; exact API runtime6.
Изменения только своей ВМС за существующим WMS_PRINT_SERIES_ENABLED; проданная
ВМС, агент, ТСД и операции склада не изменены. База выпуска — PR927/928.
