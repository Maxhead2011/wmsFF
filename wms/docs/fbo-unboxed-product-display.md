## Диагностика №2542

Клиент — ИП Королев Максим Алексеевич, `storesWithoutBoxes=true`.
Заявка ФБО Ozon 135688237-1: 8 мониторов Hawkeye H 10.2″,
ШК `2052713928520`. Настройки отображения: название, артикул, штрихкод.
На 29.10.2026 16:55 МСК сервер вернул PICKED=8, PACKED=0, этап PACKING.
Складские данные не изменялись; диагностический snapshot выполнен с откатом.

В этом режиме сервер намеренно возвращает пустой маршрут по коробам и состав
в `lines`. Экран отбора показывал только подсказку сканировать товар, а карточки
брал из `route.tasks`, поэтому до сканирования товар не был виден.

## Точечные изменения

- `FboTwoStageScreen.unboxedPickingContents`: перед полем сканирования показывает
  строки с положительным остатком к отбору: товар, нужно, отобрано, осталось.
  Используются серверные количества; после принятого скана применяется свежий план.
- `TsdFboPlan.Line`: сохраняет `productDisplayText`; `displayLabel` использует
  настройки клиента, при их отсутствии — название, артикул, размер, ШК.
- Отрисовка ограничена LOGOFF, хранением без коробов и этапом отбора.
  API, складские остатки, КИЗы, маршруты по коробам и проданные варианты не меняются.
