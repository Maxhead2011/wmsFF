# Дубль КИЗ: восстановление станции в Windows-агенте

Подготовлена версия 2026.10.10.1. Не опубликована.

В публичном архиве 2026.10.09.2 отсутствует KizDuplicate.ps1, а главный цикл
не вызывает его. Сервер показывает только станции с недавним heartbeat
отдельной очереди дублей. Поэтому работающая печать ФБС не делает станцию
доступной для дубля КИЗ.

Исправление: включить существующий модуль в архив и копирование установщика,
загрузить его при запуске и вызвать перед обработкой серий (до continue).
Ошибки очереди изолированы и записываются с меткой kiz-duplicate.
Условия филиала, пользователя, формата 58 × 40 и серверные проверки сохранены.
FBS, обычные этикетки, серия и их durable journal не меняются.
Добавлены два HTTP-запроса heartbeat/claim на свободную очередь дублей за цикл;
скорость физического принтера не измерялась. Не заявляем отсутствие сетевых затрат.

Затронуты LOGOFF-FBS-Print-Agent.ps1 (загрузка, главный цикл,
Invoke-AgentKizDuplicateCycle), Build-Package.ps1 (список файлов),
AgentLifecycle.ps1 (версия, Install-AgentFiles), два файла тестов.
API, Android, схема и остатки не изменяются. Общие исходники агента затронуты,
но выпуск предназначен только нашей WMS; проданная WMS не обновляется.

Проверки: четыре новые регрессии падают до исправления и проходят после.
31 тест исходного агента и 31 тест с распакованным установочным архивом прошли.
API: 3303 passed / 145 skipped; отдельные kiz*.integration.spec.ts исключены
(нужна выделенная БД). Web: 416 passed / 2 skipped.
Проверены ФБС, парная переклейка, одиночные этикетки, серия одним заданием,
отказ HTTP и повтор ACK без повторной физической печати.
Физический принтер недоступен локально.

После разрешения публикации: обновить только скачиваемый архив агента с
проверкой текущего production baseline, затем установить его на печатном ПК.
Сохранить stationId/настройки штатным установщиком. В «Дубль КИЗ» нажать
«Обновить / проверить печать». Проверить выбор станции, одну этикетку дубля
и контрольное сканирование. Приложение Android менять не требуется.
