# Журнал Excel и ожидание размещения ФБО

В кабинете перед скачиванием Excel сохраняется `CLIENT_STOCK_EXPORT_PREPARED`:
пользователь, серверное время, имя файла, фильтры, точные строки, количество,
SHA256 строк, IP запроса и браузер. Событие означает подготовку файла, а не
доказательство сохранения на диске. Ошибка журнала останавливает скачивание.
IP берётся из `request.ip`; без доверенного reverse proxy это может быть адрес прокси.
Шесть колонок действующего Excel сохранены. DTO также поддерживает старый формат.

Для клиентов PALLET_SORT подтверждённый приход за последние 7 суток учитывается
при создании ФБО даже без размещения. Учитывается минимум текущего AVAILABLE
остатка и положительных RECEIPT-движений того же короба/SKU/склада. Направления
приёмки соблюдаются; существующие резервы вычитаются один раз. Дубли SKU в файле
не получают один и тот же остаток дважды. Ожидание размещения показано отдельно
от реальной нехватки. В маршруте ТСД такой короб появляется после размещения
и обновления; прямой отбор до размещения отклоняется.

Изоляция: существующий `WMS_WB_ORDER_STOCK_LIFECYCLE_ENABLED`, без миграций.
Sold WMS не публикуется, поведение при выключенном флаге проверено тестами.
LOGOFF APK218 добавляет текст ожидания, остальные варианты приложения сохранены.
