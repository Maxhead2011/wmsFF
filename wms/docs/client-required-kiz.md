# Все товары клиента с КИЗ

Подготовлено в `fix/kubrin-required-receipt-kiz`, код ещё не опубликован.

В кабинете клиента добавлен переключатель «Все товары с КИЗ» с явным сохранением.
GET/PUT `/clients/:clientId/kiz-policy` используют права clients:read/write,
проверку доступа к клиенту и разделение demo. Настройка хранится в
`client.receipt-kiz-required.v1:<clientId>`, значение `{required:true}`.
Работает только при `WMS_KIZ_CLIENT_GUARD_ENABLED=true`.

Включение атомарно сохраняет настройку, выставляет карточкам клиента
needsChestnyZnak=true/isUnmarked=false и пишет журнал с автором. Остатки и КИЗы
не создаёт. Выключение сохраняет индивидуальные признаки маркировки карточек.

Приёмка проверяет правило до создания SKU/прихода, включая неизвестный ШК и
accept-with-error. Повтор уже применённой операции остаётся идемпотентным.
Поиск неизвестного ШК возвращает виртуальную маркированную карточку для запроса
КИЗа существующим ТСД; сам поиск ничего не создаёт. Ручные и импортированные
карточки, обычная и связанная синхронизация маркетплейса наследуют правило.
Импорт остатков без КИЗ для такого клиента блокируется.

Инвентаризация требует поштучный SCAN_KIZ независимо от captureKiz/requireKiz и
старых признаков карточки. Ручное изменение количества блокируется. Завершение
проверяет совпадение количества с доказательствами INVENTORY_KIZ_SCAN текущего
раунда; старый подсчёт без КИЗ требуется повторить. Существующий механизм
актуализации остатков не заменён; INVENTORY_ADJUSTMENT не превращается в приёмку.

## Применённая настройка данных — 31.10.2026

По прямому поручению Катерины проверены UUID и сохранено required=true:

| Клиент | Код | Исправлено карточек |
|---|---|---:|
| ИП Лукин Илья Ильич | CL-000001 | 37 |
| ИП Кубрин Е. В. | CL-000014 | 57 |
| ИП Елецкая Карина Равшановна | CL-000016 | 3 |

Изменения выполнены одной транзакцией, журнал CLIENT_RECEIPT_KIZ_REQUIRED
сохраняет прежние признаки всех изменённых карточек. После записи у каждого
клиента оставалось 0 карточек без маркировки. Ни один остаток, резерв или КИЗ
этой операцией не изменён. Текущий сервер использует исправленные признаки
карточек; постоянное правило и переключатель требуют публикации нового кода.
