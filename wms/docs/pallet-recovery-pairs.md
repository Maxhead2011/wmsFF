# Восстановление короба: ШК + КИЗ

Кандидат 28.11.2026: наша WMS, ТСД server-choice 280 (`0.1.280-pallet-pairs`).
База: опубликованные PR1125/API `60e7c712…`, web без изменений, APK279.

В «Паллет-сорте» ШК выбирает товар, но не увеличивает счётчик. После уникального
КИЗа добавляется одна единица. Повтор той же марки, включая другой формат сканера,
не увеличивает количество. Незавершённая пара блокирует сохранение.
После отправки состав зафиксирован; повтор сохранения использует исходный ключ.

Серверный флаг `WMS_TSD_PALLET_RECOVERY_PAIRS_ENABLED=true` включается только у нас.
Старый ТСД с количеством без КИЗ не сможет восстановить остаток после включения:
нужно обновиться до 280. Проданная WMS и стандартный канал APK270 не меняются.

Сервер проверяет клиента, филиал, ШК, уникальность марки и GTIN новой марки.
Чужой короб, ненулевой остаток/резерв, недоступный КИЗ или связь со сборкой/отгрузкой
требуют сверки. Привязанный к другому коробу или учёту без коробов КИЗ автоматически
не переносится. Существующая марка восстанавливаемого короба сохраняет ID и историю.
Serializable-транзакция и блокировки короба/КИЗа защищают приход; повторный запрос
не создаёт движения. Размещение можно повторить после прерывания ответа.

Изменения: `MainActivity` — шесть методов восстановления и изолированные лямбды;
`PalletRecoveryPairs` — состояние пары; API `restoreTsdPalletBox` и новый помощник.
Runtime накладывается точечно: два API-модуля, Android поверх подписанного APK279.
1508 остальных методов MainActivity и все ресурсы APK сохранены; sourceParityVerified=false.

Проверки: API 5050 passed/203 skipped (отдельный KIZ duplicate integration без БД
исключён); Android384; 14 ранее существовавших ошибок TypeScript, новых нет.
Изолированная PostgreSQL: незавершённая пара, повторный/одновременный запрос,
сохранение существующей марки, отсутствие повторного прихода и начислений.
Подписанный APK280 на эмуляторе: ШК=0, КИЗ=1, повтор=1, незавершённое сохранение
заблокировано, повтор после ошибки сети отправляет тот же состав/ключ.
Проверка callback обновления279 сохранена. Физическая печать и восстановление
реального складского остатка не выполняются при проверке выпуска.

Воспроизводимые scripts: `scripts/releases/pallet-recovery-pairs/`.
