# Семь плиток FBS

Подготовлено 24.10.2026, не опубликовано. PR в `feature/wb-print-check` из `fix/fbs-seven-tile-layout`.

Первая плитка «Активные заказы» занимает два ряда слева. Верхний ряд: 2 «Проблемные заявки», 3 «Управление автоматическим распределением остатков», 4 «Архив заявок». Нижний: 5 «Отчёт по товарам FBS», 6 «Настройки стоимости», 7 «Пропуска WB».

«Штрафы по FBS» доступны внутри «Проблемных заявок», вместе с контролем автоотмены и повторным довозом. Сохраняются существующий отчёт, фильтры, экспорт и права. При выборе штрафов выделяется плитка проблем. Штрафы остаются только для WB. На узком экране первая плитка сверху, остальные идут компактной сеткой.

Файлы: `FbsPanel.tsx` (compactFbsViewGroup, visibleViews, subnav, layout marker), `fbs.css` (изолированная сетка), `FbsCompactMenu.spec.tsx` (две регрессии), `scripts/tests/fbs-seven-menu-browser.cjs`, `scripts/releases/fbs-seven-menu-20261024/{patch.cjs,release.py}`.

Тест до изменения воспроизводил восемь плиток и отсутствие штрафов в группе; после правки проходят 11 тестов меню. Общие web487/API3590, TypeScript; 2/155 пропущены, отдельная KIZ DB suite недоступна. Runtime browser: 12 групп проверок, включая фактические координаты 1 / 2–4 / 5–7, штрафы внутри проблем, три ширины, Panthera light/dark, прежние пять разделов распределения и архив. API подменены учебными данными.
