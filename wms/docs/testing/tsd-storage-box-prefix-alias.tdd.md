# TSD storage-box prefix alias

Request: accept `FFL_LKBBOX` for destination storage boxes in WMSFF2207.
Production policy previously allowed only `FFL_BOX_` as the storage prefix.

## Change and isolation

- `BoxCodePolicyService.requireStorageBox`: accepts the primary prefix plus explicitly configured `storageBoxAliases`, still requiring a suffix.
- `normalizeBoxCodePolicy`: normalizes and validates aliases; default is empty.
- `updatePolicy`: legacy settings-screen saves preserve aliases when that property is omitted; explicit `[]` removes them.
- Primary prefix generation, ordinary box validation, stock and KIZ business logic are unchanged.
- Enable `FFL_LKBBOX` only in WMSFF2207's `warehouse.boxCodePolicy` setting. No sold-VM configuration or release.
