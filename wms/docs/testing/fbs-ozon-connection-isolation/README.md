# FBS: ошибки отдельных подключений Ozon

Ветка исправления: fix/fbs-ozon-connection-isolation, база: feature/eleonora-screen-voice.

Причина: Promise.all прерывал весь ответ клиента, когда дополнительное активное подключение Ozon имело некорректный Client-Id. На момент диагностики исправный кабинет Бушковой возвращал три заказа awaiting_packaging, дополнительный — HTTP 400.

Модуль fbs-connection-results.ts сохраняет успешные ответы и отдельные предупреждения. Прямой операционный загрузчик текущей Git-ветки остаётся строгим. Опубликованный код содержит более поздний путь readOnly; published-service.patch фиксирует точное подключение исправления к нему (git apply --unidiff-zero, только к указанному baseline). Не заменять весь текущий production service старой Git-копией.

Флаг WMS_FBS_CONNECTION_ISOLATION=true включает частичные результаты только при options.readOnly=true. Рабочие операции не получают частичные данные. При полном отказе загрузчик отклоняет результат, сохраняя последний успешный снимок. Ошибка не содержит исходный ответ API или ключи. Сообщения и connectionErrors фильтруются по видимым подключениям выбранного филиала. Уже существующий UI выводит их через sync.error.

Изменяемые функции: collectFbsConnectionOrders, fbsConnectionIsolationEnabled, loadFbsOrdersUncached, listFbsOrdersForDisplay (последняя — в опубликованном адаптере). Общий marketplace-connections.service.ts затронут; для проданной ВМС флаг по умолчанию выключен, строгая загрузка сохранена. Миграций нет. Настройки подключений не изменяются.

Проверки: до исправления helper-тесты воспроизводили три ошибки, опубликованный service — две. После исправления все 10 целевых тестов актуального серверного кода прошли; TypeScript-сборка прошла. Полный локальный прогон API: 2654 passed | 93 skipped (2747). TypeScript --noEmit прошёл. Наборы с недоступной тестовой БД отключены штатной настройкой, без изменения тестов. Тесты не подключаются к производственной БД. verification.json подтверждает, что в образе изменены только service и новый helper (src/dist).
