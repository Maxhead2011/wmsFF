# Режим сортировки без КИЗ: подготовка выпуска

PR 207: `feature/sorting-barcode-only` → `feature/service-unprinted-kiz-search`.

Новый режим требует `WMS_PALLET_SORTING_BARCODE_ONLY=true` вместе с существующим флагом сортировки. Включать только на нашей ВМС. Одна единица AVAILABLE переносится из явно указанного подтверждённого короба; привязанные КИЗ не выбираются автоматически. Сессии без scanMode остаются в режиме ШК + КИЗ. Отдельного изменения схемы БД нет.

Локальные проверки: 2319 API-тестов, 201 web-тест, 81 Android-тест. На актуальном серверном кандидате прошли TypeScript и 6 новых API-тестов. Android подготовлен из опубликованных исходников версии 190: 984 теста в шести вариантах и сборка debug прошли. Функции версии 190 сохранены; новый APK пока не подписан и не опубликован.

Для проверки наложения Android сохранён [патч к версии 190](../../infra/patches/sorting-barcode-android-190.patch). Он включает экран и новые русские/узбекские/английские подписи. Два новых Java-файла PalletSortingScanMode и PalletSortingScanModeTest брать из этого PR. Патч относится только к указанной основе; перед будущей установкой сверить текущую версию приложения. При несовпадении основы не применять вслепую. Локальная версия Gradle в рабочей ветке старее production и не предназначена для публикации.

На этапе подготовки не выполнялись изменения остатков, настроек production, слияние PR или перезапуск рабочих контейнеров. Перед установкой нужны свежая проверка основы, уникальная версия logoff, штатная подпись APK, проверка обновления с сохранением настроек, подтверждение текущих образов и резервный путь отката. Проданную ВМС не публиковать.
