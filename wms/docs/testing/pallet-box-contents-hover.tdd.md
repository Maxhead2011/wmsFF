## Поведение

- Наведение на название короба: задержка 250 мс, затем read-only карточка.
- Клавиатурный фокус и нажатие (в том числе на сенсорном экране) тоже открывают карточку.
- Перечень: название, артикул, цвет, размер, ШК, количество и подпись статуса остатка.
- Загружаются все `contents` существующего `fetchTurnoverBoxDetails`, только для
  одного выбранного короба, с `clientId`. Серверные stock:read/client/warehouse проверки сохранены.
- Данные не берутся из истории отгрузок и не вычисляются из количества КИЗов.
- Пустой короб, отсутствующий короб, загрузка и ошибка доступа различаются.
- При ошибке доступна повторная загрузка. На новом открытии данные обновляются;
  одновременные события одной загрузки объединяются, старые ответы после смены контекста игнорируются.
- Карточка находится в portal, не обрезается контейнером таблицы. Внутри есть прокрутка.
- Escape, крестик и нажатие снаружи закрывают карточку. При закрытии кнопкой фокус
  возвращается к исходному коробу без повторного автоматического открытия.
- Событие открытия заменяет предыдущую карточку: даже клавиатурный фокус не оставляет два окна.

## Воспроизведение браузерной проверки

Из `apps/web`, с заранее установленным Playwright и Edge:

```powershell
$env:PLAYWRIGHT_MODULE = '<путь к установленному модулю playwright>'
$env:PREVIEW_ARTIFACT_DIR = '<каталог тестовых скриншотов>'
node e2e/storage-box-preview.mjs
```

Тест запускает localhost:22954 и закрывает браузер/сервер по завершении.
Проверены hover, 20 строк товара, прокрутка, Escape, фокус, замена карточки,
пустой/отсутствующий короб, ошибка/повтор, отсутствие данных предыдущего короба,
неизменность кнопок действий, тёмная тема и границы на 375/768/1440 px.
Скриншоты реального компонента с **тестовыми**, не production-данными:
`C:/WMSFF2207/tmp/box-hover-browser/desktop.png`, `dark-375.png`, `dark-768.png`, `dark-1440.png`.

В первом запуске браузерного теста исправлена неполная фикстура (`googleSync`);
это не ошибка production-кода. В проверке переключения использован доступный мышью
соседний короб: часть соседней строки закономерно может перекрываться самой карточкой.
