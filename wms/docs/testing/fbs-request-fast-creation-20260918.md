# Создание FBS-заявки без полной синхронизации

Ветка: `fix/fbs-request-fast-creation-20260918`.
База предполагаемого PR: `fix/fbs-transfer-started-at`, `c4ff8abc`.
Production не изменён. Не выкатывать весь checkout поверх production: там есть дополнительные изменения.

## Область изменения

- `MarketplaceConnectionsService.createFbsRequest`: при `WMS_FBS_FAST_REQUEST_CREATION_ENABLED=true`
  вызывает отдельную выбранную загрузку, не присоединяясь к общей истории/начислениям.
- `loadFbsOrdersUncached`: необязательный серверный фильтр выбранных подключений и заказов;
  выбранный вызов всегда использует `readOnly: true`, `billingMode: skip`.
- `fetchSelectedWildberriesFbsOrders`: текущие новые заказы и свежие статусы только выбранных ID,
  пакетами не более 1000. История и довозы не загружаются. Исторический cache используется
  только как источник метаданных, не как подтверждение актуальности статуса.
- `FbsPanel`: сохранение заявки не ждёт последующего обновления списка.

Не изменены маршрутизация филиалов, запрет дублей, проверка клиента, карточек товара,
  статусов, транзакция создания, начисления и остатки. Не вызываются WB write endpoints.
Без флага API работает по старой ветке; в проданном окружении флаг не включать.
Web-изменение только разделяет завершение действия и обновление списка; отдельного
  изменения данных не выполняет. Чужое окружение не публиковалось.

При холодном кеше выбранный заказ, которого уже нет среди новых WB-заказов, требует
  обновления списка: никакой молчаливой загрузки всей истории или принятия старого статуса.
Заявки из поставки с переданным внутренним responseOverride сохраняют прежнюю логику.
Для Ozon/Yandex остаются их существующие загрузчики; оптимизация сетевого чтения относится к WB.

## Публикация отдельно

После согласования PR и проверки текущего release применить только данный патч и включить
`WMS_FBS_FAST_REQUEST_CREATION_ENABLED=true` только на LOGOFF. Проверить реальное время
выбранного запроса и отдельного обновления списка. Миллисекунды unit-теста не являются
замером скорости WB/production. Откат: отключение флага возвращает прежний API-путь.
