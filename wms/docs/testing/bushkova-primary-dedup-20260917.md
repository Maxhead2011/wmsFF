# Бушкова: точная отмена повторных черновиков первичной обработки

Область: наша WMS, ИП Бушкова И.М. (`1757a389-c0d4-49b5-9347-2bde0c549260`),
Москва (`afb244a1-50ae-4ae6-9111-afe85949fa58`), 01.08–15.09.2026.
Константин разрешил исправить подтверждённые дубли, не затрагивая выставленные/оплаченные счета.

## Доказательство и границы

55 пересечений «заказ + услуга» НЕ равны 55 доказанным дублям. Старые начисления
содержат номера всех заказов поставки, даже когда конкретная услуга выполнена только
по части товаров. Частичные пересечения не исправляются автоматически.

Предварительно доказаны 8 одинаковых начислений по дате/поставке в 7 целиком
повторных черновиках на 829,78 ₽. Сопоставлены клиент, филиал, marketplace/connection,
serviceId, полный набор заказов, единица, количество, тариф, сумма, базовая цена,
налоговый режим и billingAttemptId. История повторной сборки исключает автоисправление.
Выставленные/оплаченные счета и любые счета с записями оплат исключены.

## Риски и проверки

Риск — ошибочная отмена финансового документа. Снижается строгим полным совпадением,
снимком для подтверждения, ограничением клиент/филиал/период, запретом править оплаты,
повторные сборки и смешанные счета. Для повторного создания источника требуется
включённая действующая защита `WMS_WB_ORDER_STOCK_LIFECYCLE_ENABLED=true`.
Никакого переноса патча в проданную WMS; скрипт жёстко ограничен клиентом и филиалом.
API, ТСД, расчёт хранения, тарифы, FBS-начисления и номенклатура не меняются.

До реализации 3 положительных/защитных теста падали; после 20 тестов планировщика PASS.
Полный локальный набор API: 2658 PASS / 63 SKIP. Web: 232 PASS.
Проверка типов API/web и `node --check` PASS.
Перед применением обязательны свежая резервная копия, восстановление в отдельную БД,
проверка операции на копии и повторного запуска. Результат сохраняется рядом с backup.

Репетиция выполнена на изолированной PostgreSQL-копии свежего дампа: отменены ровно
8 начислений / 7 черновиков, снижение активных начислений 829,78 ₽. Повторный apply
возвращает ранее записанный аудит, повторных изменений нет; последующий preview пуст.
Рабочие данные на этапе репетиции не изменялись.
