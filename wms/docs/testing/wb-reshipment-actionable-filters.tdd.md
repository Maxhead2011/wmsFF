## Контракт и влияние

- `fbs-reshipment.ts`: `reshipmentVisibility` классифицирует свежие структурированные статусы WB. Полученные/отменённые и обычная доставка скрыты. Подтверждённый список переотгрузки или доказанный возврат на сборку показывается, в том числе с локальной блокировкой для разбора.
- `fbs-reshipment.service.ts`: `inspect` сохраняет исторический опрос и полные результаты для проверки записи; только `check` фильтрует выдачу. Неизвестный/отсутствующий индивидуальный статус учитывается в `unverifiedCount`. Ошибка транспорта прерывает проверку явно. Сохранённые операции не фильтруются вместе с кандидатами.
- `FbsReshipmentPanel.tsx`: поиск по словам (номер заказа/заявки/поставки, ШК, артикул, название), кабинет, доступность для текущего действия; выбор всех доступных видимых заказов и снятие выбора. Нельзя молча выбрать первый кабинет или первые 100. При превышении 100 или нескольких кабинетах требуется уточнить фильтр. Изменение фильтра/режима сбрасывает выбор, предварительную проверку и подтверждение.
- `api.ts`: обратно совместимый необязательный `unverifiedCount` в типе ответа.
- Тесты: два API spec, web spec и `test/fbs-reshipment-browser.cjs`.
- Не изменены права, БД/миграции, остатки, КИЗы, маршруты создания/продолжения операции и feature flag. Проданное окружение и FFULHAB не затрагиваются; default-off сохранён. Общие исходники API/web меняются только в отдельной ветке нашей WMS.

WB `supplierStatus=complete` означает доставку, а не получение покупателем (`wbStatus=sold`). Источник: https://dev.wildberries.ru/en/docs/openapi/orders-fbs?locale=ru .
