таймеры. Четыре таймера загрузки заказов/клиентов приостанавливаются внутри
распределения остатков. Модуль подключений сохраняет `WbSyncHealth` и
`FbsSizeSubstitution`. Клиент API сохраняет функции замены размеров.

Новые возможности включаются только на нашей ВМС через
`WMS_MARKETPLACE_ALLOCATION_ENABLED=true`. Публикация остатков остаётся выключенной:
`publicationEnabled=false`. Миграций, изменения конфигурации БД и складских записей нет.

Перед переключением требуется:

1. Проверить образы и отсутствие изменений исходников внутри контейнеров.
2. Собрать API/web и выполнить тесты новой функции.
3. Сравнить полный набор серверных API-тестов с исходным образом: старые серверные
   тесты расходятся с установленными выпусками; новые ошибки недопустимы.
4. Проверить неизменность исходников вне патча и сохранность всех прежних assets/загрузок.
5. Переключить под обеими блокировками выпуска API/web, сохранив старые теги для отката.
6. Проверить health, реальные образы, переменные окружения и возможности нового сервиса.
