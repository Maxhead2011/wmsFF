# Готовность Ozon вместо дедлайна

В списке сборок Ozon блок срока становится зелёным с текстом «Готово к отгрузке» и «Дата сдачи: … МСК» после подтверждения грузомест. Для каждой заявки Ozon требуются зафиксированный состав (`frozenHash`), непустой список поставок, SUCCESS без ошибки и полученные cargoId для всех поставок. Частичная или неопределённая передача сохраняет прежний дедлайн. Общая сборка проверяет каждую заявку Ozon отдельно.

Дата сдачи берётся из сохранённого `SupplyOrderSnapshot.date`, не из editDeadlineAt и не из даты создания WMS. Если дата отсутствует/некорректна, выводится «Дата сдачи: не указана в Ozon». Старое предупреждение об актуальности дедлайна в готовом блоке скрыто.

Файлы: ozon-shipment-caption.ts (read-only проекция), OzonFboImportService.list, тип OzonEditDeadline, OzonEditCountdown и его CSS. Существующее ограничение интерфейса нашей ВМС сохранено. База, операции передачи, остатки, статусы заявок, биллинг и ТСД не изменяются. Это подготовленное изменение, не запись о публикации.

Тесты: регрессия готовой заявки воспроизведена на старом UI; проверяются частичные/ошибочные подтверждения, отдельные заявки общей сборки, отсутствие даты, отключённый контур и часовой пояс Москвы.

Проверено локально: API5038 passed/203 skipped (отдельная KIZ duplicate integration DB исключена), web701 passed/2 skipped, TypeScript web без ошибок; точечные8 тестов расчёта статуса прошли после финальной правки. Публикация не выполнялась.
