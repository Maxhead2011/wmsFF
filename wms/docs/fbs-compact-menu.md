# Компактное меню FBS

Подготовлено 24.10.2026, **не опубликовано**. Ветка `fix/fbs-stock-management-menu`, целевая ветка PR `feature/wb-print-check`.

## Состав меню

1. Активные заказы по FBS.
2. Проблемные заявки: контроль автоотмены и повторный довоз.
3. Управление автоматическим распределением остатков.
4. Архив заявок: отгруженные и отменённые заказы.
5. Отчёт по товарам FBS.
6. Настройки стоимости: стоимость обработки, калькулятор, назначение стоимости обработки.
7. Пропуска WB.
8. Штрафы по FBS.

Отдельные плитки «Товары FBS» и «Короба WMS» убраны. Короба, движения и серверные операции не удаляются. В опубликованном разделе распределения уже существует меню из пяти подразделов: между маркетплейсами, резервы и предпросмотр, между артикулами, между складами, подтверждение остатков WB. Кандидат сохраняет этот раздел целиком; управление товарами остаётся внутри него.

Полученные покупателями заказы из прежнего архива сохранены внутри «Отгруженных» отдельным списком с прежними read-only контролами. Отмена/экспорт, фильтры и поиск остаются в существующих компонентах. Назначение тарифов и калькулятор сохраняют проверки прав. WB-инструменты не появляются в Ozon/Яндекс.

## Файлы и изоляция

- `apps/web/src/components/fbs/FbsPanel.tsx`: группировка плиток, активное состояние подпунктов, навигация архива/стоимости/проблем, сохранение завершённых заказов.
- `FbsStockAllocationSection.tsx`: адаптер исходного интерфейса распределения с загрузкой по открытию и ключом клиента/кабинета; применяется только при `VITE_FBS_COMPACT_MENU_ENABLED=true`.
- `fbs.css`: локальные стили вкладок и раскрываемых настроек.
- `FbsCompactMenu.spec.tsx`, два browser-скрипта в `scripts/tests`: регрессии и проверка собранного интерфейса.
- `scripts/releases/fbs-compact-menu-20261024/patch.cjs`: точечное изменение только функции навигации в фактически опубликованном FBS-модуле и четыре помощника отображения. Все функции бизнес-операций и действующий расширенный раздел распределения сохранены побайтно.

По умолчанию исходный интерфейс сохраняется. Проданная WMS не публикуется и не получает флаг. API, схема БД, APK, учёт, резервы, расчёт стоимости и политики распределения не меняются.
