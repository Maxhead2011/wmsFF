# Измерение задержек за смену 10:00–22:00 МСК

Сводка всех завершённых API-ответов дополняет существующий выборочный журнал.
Последний сохраняет все медленные ответы до лимита и лишь 1/100 быстрых, поэтому
его нельзя использовать для p50/p95 всей смены.

`operation-histogram.ts` хранит счётчики и неперекрывающиеся интервалы длительности
по шаблону маршрута. Раз в минуту выпускается одна JSON-запись, включая пустые окна.
Не более 128 отдельных маршрутов плюс overflow; количества overflow сохраняются.
Границы: 10/25/50/100/250/500/1000/2000/5000/10000/30000/60000 мс и выше.
Квантили по ним — интервалы, не точные значения. Среднее вычисляется по сумме
длительностей и количеству, а не усреднением минутных средних/квантилей.

Записываются количество, сумма, максимум, неуспешные завершения, HTTP 4xx и 5xx.
Тела, URL-параметры, идентификаторы товаров/КИЗов, токены и trace ID в сводку не входят.
Ошибка вывода не влияет на складскую операцию. Таймер unref не удерживает процесс.
При аварийной остановке последняя незавершённая минута может потеряться; отсутствие
окон следует показывать как пробел измерений, а не как нулевую нагрузку.

Новый флаг `WMS_OPERATION_HISTOGRAM_ENABLED` по умолчанию выключен. Включается только
в нашем API-образе; также требуется существующий `WMS_OPERATION_TIMING_ENABLED`.
Два диагностических модуля поверх проверенного runtime. Web, APK233, печать, БД,
настройки резервирования/лог-ротации и проданная ВМС не изменяются.

Проверки: 3 новых теста + 6 существующих диагностических; actual-runtime smoke4
с 1000 ответами и выключенным флагом; API3490/155 skipped, web445/2 skipped,
TypeScript API. Исключён прежний KIZ integration suite без отдельной БД.
Изменённый исходный модуль до правки структурно совпадает с опубликованным JS.

Первые данные 16 октября начинаются после публикации и не покрывают начало смены.
Следующую смену необходимо собрать целиком; отдельно указать покрытие, перезапуски,
количество наблюдений и операции без сканов. Время ответа сервера не включает
распознавание камерой ТСД и весь сетевой путь устройства. Детализация ожиданий БД
и внешнего API остаётся отдельным этапом, этот выпуск её не подменяет.
