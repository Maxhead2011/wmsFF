# Упаковка по заранее переданному составу Ozon

Только наша ВМС, флаг `WMS_OZON_PLANNED_PACKING_ENABLED=true`. Проданная ВМС и её APK не публикуются.

План хранится отдельно от физических единиц: направление, SKU, количество, зона размещения, ШК FFL и подтверждённый cargo ID Ozon. Передача плана не создаёт сканы, не списывает остатки и не начисляет услуги.

ТСД 270: товар → КИЗ, если требуется → подсказка конкретного короба → ШК FFL либо стикер этого грузоместа Ozon. Разрешён только соответствующий короб. Сервер повторно проверяет идентификатор отобранной единицы, SKU и свободную квоту под блокировкой заявки. Идентификаторы единицы и операции сохраняются при потере ответа и перезапуске. Уже упакованная единица не расходуется повторно даже с новым идентификатором операции. Одинаковый немаркированный товар физически неразличим по общему EAN: защита относится к повтору операции/единицы; сам EAN не является уникальной меткой экземпляра.

Короб закрывается только при точном совпадении состава. Ручной обход, упаковка целиком и изменение отправленного состава запрещены. Отбор по подтверждённому плану продолжает работать благодаря PR1103. При неподтверждённой корректировке Ozon сохраняется блокировка.

Новые планы сверяются с полной потребностью заявки и свежим составом Ozon. Разные зоны SORT/NON_SORT не смешиваются. Отправка направлений последовательная, с записью намерения до вызова API. Потерянный ответ не повторяется автоматически. Активация происходит после чтения фактических cargo ID и точного состава каждого грузоместа. Непустые чужие грузоместа автоматически не заменяются.
