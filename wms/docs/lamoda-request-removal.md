# Lamoda: удаление созданной заявки

Опубликовано 28.10.2026 через PR727, `fix/lamoda-request-removal` → `feature/wb-print-check`. На публичном сайте повторно прошли 50 сценариев интерфейса/удаления и 8 сценариев дефицита, без ошибок JavaScript. Тестовые API полностью перехвачены; реальные заявки не изменялись.

В карточке созданной активной сборки Lamoda отсутствовала кнопка удаления, хотя общий серверный механизм уже поддерживает OUTBOUND-заявки. `LamodaPanel.tsx` подключает существующие `RequestRemovalProvider` и `RequestRemovalButton` с **requestId сборки**, не ID черновика. Наличие кнопки определяется серверной capability; права администратора/собственника, область клиента/филиала и все физические блокировки остаются на сервере.

Используется прежнее подтверждение: причина, номер, галочка; предпросмотр и ревизия повторно проверяются под блокировкой заявки. После успеха список обновляется, открытое выполнение и предпросмотр очищаются; отменённая заявка остаётся в завершённых. Смена клиента/кабинета/активного филиала сбрасывает окно подтверждения. Модальное окно расположено вне CSS-контейнера карточек. Черновики без созданной заявки не получают эту кнопку. Поставка в Lamoda не отменяется.
