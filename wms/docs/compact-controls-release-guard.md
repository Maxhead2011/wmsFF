# Защита оформления заявок и Ozon

Проверка `scripts/check_compact_controls.cjs` закрепляет четыре кнопки склада
в двух рядах и двух столбцах. Проверяются оба ряда, компактная высота,
отсутствие обрезанного текста, раскрытие документов и выделение выбранного
режима Ozon. Матрица: 1440/1920/390 px, шрифт 16/20 px, светлая/тёмная тема,
FBO/FBS — 24 сценария.

## Автоматически в PR

Workflow `compact-controls.yml` запускается для каждого PR в
`feature/la_panthera` и после слияния. Он проверяет реальный каскад исходных CSS,
включая импорт через `marketplace-surfaces.css`, и сохраняет результат/скриншот.
Три отрицательных теста доказывают, что потеря импорта, один столбец и потеря
оформления Ozon завершаются ошибкой проверки.

Разметка сценария синтетическая, рабочие заявки не меняются. Проверка не заменяет
интеграционные тесты React и проверку конкретного опубликованного артефакта.
Статус CI должен быть зелёным перед слиянием. Этот workflow сам по себе не меняет
правила защиты веток GitHub и не блокирует старые сторонние deploy-скрипты.

## Перед каждой публикацией web

1. Сверить свежие image ID с текущей базой. Пока `sourceParityVerified=false`,
   сохранять существующие web-ресурсы и подключения CSS из актуального runtime.
2. Запустить **точный готовый кандидат** на изолированном HTTP-адресе.
3. Установить `PUBLIC_URL` в этот адрес и выполнить:

   ```text
   node wms/scripts/check_compact_controls.cjs work/controls-candidate
   ```

   Ошибка — остановить публикацию. Режим `--source` не является заменой этой
   проверки: он не доказывает наличие стилей в образе.
4. После выпуска повторить ту же команду для публичного адреса и сохранить
   `controls-check.json` и `controls.png` вместе с доказательствами выпуска.
   При регрессе вернуть предыдущий проверенный web-образ.

Для локальной проверки исходников:

```text
node wms/scripts/check_compact_controls.cjs work/controls-source --source
node wms/scripts/test_compact_controls_guard.cjs work/controls-negative
```

Требуется Playwright. `PLAYWRIGHT_MODULE` позволяет указать установленный модуль,
`PLAYWRIGHT_CHANNEL=msedge` — локальный Edge; CI использует Chromium.
`CONTROLS_SOURCE_ROOT` используется отрицательными тестами для изолированной копии.
Выводы и тестовые копии сохранять только в `work/`.

Изменение касается только инструментов проверки нашей WMS. API, статусы, остатки,
проданная WMS и действующие стили не изменяются.
