# FBO WB: восстановление оформления при прямом входе

Подготовлено 28.10.2026 от опубликованного PR735 (`2026-10-28-lamoda-relabel`). Первоначальная база PR731 была заменена после проверки параллельного выпуска.

## Причина и область исправления

В опубликованной сборке FboWorkspace загружает ClientRequestsPanel как внешний JS-модуль. При этом не выполняется Vite preload его CSS. На холодном входе FBO → WB окно онлайн-сборки получает `position: static`, а сортировка, архив и действия отображаются без оформления. Затронуты также клиентские кнопки редактирования/отмены.

`FboWorkspace.tsx` явно импортирует client-requests.css, request-action-menus.css, request-batch.css и fbo.css. Обработчики, права и API не изменены. Модуль принадлежит включаемому флагом контуру нашей WMS; ветка и сервер проданной WMS не затрагиваются.

Из-за `sourceParityVerified=false` публикация не использует полный локальный dist: в актуальный index.html добавляется ссылка на уже опубликованный `/assets/ClientRequestsPanel-DSREBZ1c.css`. Это единственный изменённый файл образа. JS, CSS, API, APK237 и схема остаются байт-в-байт прежними.

## Проверки

- `FboWorkspaceStyles.spec.ts`: сборка с внешними lazy-панелями обязана сохранить CSS модального окна, сортировки и кнопок.
- `scripts/tests/fbo-wb-styles-browser.cjs`: реальные опубликованные JS/CSS, новая браузерная сессия, учебные API-данные, запрет записей. До исправления воспроизведён `position: static`.
- Кандидат: OWNER 9 проверок × modern/la_panthera (включая 768/390 px), CLIENT 7 × обе темы, без ошибок JS и запросов записи. Клиенту не добавляется административная кнопка «Онлайн».
- Web на финальной базе PR735: 536 passed / 2 skipped; API: 3887 passed / 155 skipped. Две отдельные KIZ integration suites исключены без настроенной БД. Повторный полный запуск с четырьмя workers устранёнными конкурирующими тяжёлыми сборками прошёл; первоначальные 5-секундные таймауты документированы в рабочих логах.
- TypeScript и production build прошли; baseline verify/materialize/check-candidate подтвердили нулевой API delta; 8 тестов защиты baseline прошли.
