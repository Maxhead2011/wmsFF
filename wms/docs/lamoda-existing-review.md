# Проверка плана после создания сборки Lamoda

Предпросмотр импорта относится к исходному файлу и свободному остатку до создания
заявки. Его нельзя использовать как редактор уже зарезервированной сборки:
собственный резерв уменьшает свободный остаток, а исходный файл сохраняется.

В карточке созданной заявки используется «Открыть сборку». Проверка соответствий
и корректировка количеств остаются у черновиков. После создания или открытия
сборки старый предпросмотр очищается. Если список устарел и API вернул
`existingRequest`, вместо заблокированных полей и ложного дефицита отображается
переход к существующей заявке. Чтение доступно независимо от права создавать
новую сборку; серверные ограничения доступа сохраняются.

Заявка №2506 проверена без записи: статус IN_WORK, этап PICKING, четыре позиции,
21 единица. Исходный файл содержит пять позиций и 29 единиц. В рамках исправления
состав, отбор, резервы и исходный файл не меняются. Редактирование начатого отбора
этой правкой не добавляется.

Изменения: `LamodaPanel.tsx`, `LamodaStockReview.tsx`, тип `LamodaPreview` в
`lib/api.ts`. Автоматический тест в `LamodaStockReview.test.tsx` воспроизводит
ошибку до исправления. Браузерная проверка дополнительно проверяет создание,
конкурирующий резерв, устаревший список, переход к существующей заявке и отсутствие
повторной записи. Широкая проверка сохраняет удаление заявки и остальные контуры.

APK и проданная ВМС не изменяются. `sourceParityVerified=false`: полный исходный

образы, точный состав файлов, результаты браузерных тестов и merged PR.
