Опубликовано 28.10.2026 через PR721 из `fix/lamoda-inline-assembly`, поверх PR720. Проверка публичного сайта: 28 сценариев, ошибок JavaScript нет. API и остальные контейнеры не перезапускались.

## Точечные изменения

- `LamodaPanel.tsx`: общий с Ozon `FboTwoStagePanel` открывается с `embedded=true` в рабочем режиме. После создания заявки загружается её план; пользователь сразу видит онлайн-выполнение. Обновление списка сохраняет открытую сборку. Смена клиента/кабинета/филиала или выход аннулируют запоздавшее открытие. Смена заявки сбрасывает внутреннее состояние общего компонента через `key`.
- `lamoda.css`: отступы встроенного блока, перенос заголовка и горизонтальная прокрутка таблицы внутри панели.
- `scripts/releases/lamoda-inline-20261028`: проверка полного runtime и публикация трёх web-файлов поверх проверенного PR720. API, схема, ТСД, остатки, права и внешние операции не меняются. Проданная ВМС не публикуется; встроенный вид включается только в operational-режиме нашей ВМС.
