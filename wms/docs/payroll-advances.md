# Авансы и зачёт переплат ФОТ

Опубликовано 24.11.2026 через PR1070 в нашей WMS. Целевая ветка `feature/la_panthera`; [проверки выпуска](releases/payroll-advances-1070.json).

Флаг `WMS_PAYROLL_ADVANCES_ENABLED=true` включается только в нашей WMS после миграции `20261124170000_payroll_advances`. Без флага сохраняется прежний порядок выплат. Проданная WMS не изменяется.

## Поведение

Форма: сотрудник, дата выдачи, сумма, основание. Сводка выбранного периода: неоплаченный заработок, выданные за период авансы, незачтённый остаток (включая прошлые периоды), зачёт, сумма к выдаче. Избыток переносится; отрицательной выплаты нет. Объединённые карточки имеют общий баланс.

Сервер предварительно рассчитывает выбранные неоплаченные строки. Изменившиеся начисления или остатки требуют нового расчёта. Выплата, зачёт и журнал сохраняются в одной serializable-транзакции; идентификатор операции защищает повторы. Отмена отметки обычной выплаты возвращает соответствующий зачёт. Использованный аванс нельзя отменить кнопкой отмены ошибочного аванса.

`PayrollAdvance` хранит выдачи и переплаты, `PayrollAdvanceUse` — зачёт по строкам, `PayrollPaymentRun` — идемпотентность выплат. SQL параметризован; новый generated Prisma client для overlay не требуется. Миграция аддитивная, суммы — целые копейки.

## Исправление оплаченной смены

`PayrollService.correctPaidShiftWithCredit` — служебная операция OWNER без публичного маршрута. Проверяет версию смены, оплату и ожидаемую переплату. В одной транзакции исправляет окончание, пересчитывает заработок, сохраняет исходный оплаченный снимок и дату выплаты, создаёт переплату к зачёту. Повтор не создаёт второй кредит. Обычная смена статуса такой корректировки запрещена до отдельной сверки.

Согласованный случай исправлен в рабочей базе: 7 ноября, окончание 21:06 МСК (точная совместная отметка 21:06:25.966); исходно выдано 7 921,38 ₽, исправленный заработок 3 536,99 ₽, переплата 4 384,39 ₽. Повтор операции не создал второй кредит. Предварительный расчёт за 13–23 ноября: заработано 22 625,34 ₽, зачёт 4 384,39 ₽, к выдаче 18 240,95 ₽. Следующая выплата не отмечена оплаченной; остаток кредита сохранён для её подтверждения.
