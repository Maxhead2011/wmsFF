# Компактное подтверждение упаковки ФБО

Только наша ВМС: `WMS_FBO_COMPACT_PACKING_ENABLED=true`, LOGOFF APK219.
Существующие проверки операции и идемпотентность сохранены. После подтверждённой
упаковки API добавляет `packing` версии 1: абсолютные счётчики строк и коробов из
одного RepeatableRead-снимка. История отобранных КИЗов и маршрут не передаются.
Повтор операции и проверка потерянного ответа возвращают актуальные счётчики,
не выполняя повторное списание. Если компактное чтение не удалось, подтверждение
сохраняется и старый путь обновления остаётся доступным.

ТСД применяет ответ только в упаковке, для той же заявки и этапа. Поле сканирования
остаётся на месте между коробом, ШК и КИЗом. Все новые сканы требуют серверного
подтверждения предыдущей операции. При изменении этапа/состава или отсутствии
компактного ответа выполняется полная сверка. Начальный вход также загружает план.
Правки другого упаковщика отражаются абсолютными данными следующего ответа;
каждое вложение проверяется сервером, независимо от состояния экрана.

Runtime пока отличается от TypeScript (`sourceParityVerified=false`). Действующие
`actAcknowledged` и `operationStatus` находятся в проверенном baseline. Скрипт
`build-fbo-compact-packing.cjs` добавляет к ним вызов типизированного
`fbo-packing-receipt.ts`, не заменяя сервис устаревшей полной сборкой. Тест
`fbo-compact-packing-runtime.cjs` проверяет именно эти опубликованные методы.
Контроллер и DTO запросов не меняются; прежние приложения игнорируют новое поле.

Проверки: unit API, runtime ACK/retry/status, Android абсолютные счётчики,
потеря ответа и сохранение поля ввода без GET плана. Два Android-сценария падают
на предыдущем экране и проходят после исправления. Рабочая заявка1813 в откатываемой
транзакции: 1462977→82487 байт, формирование136→26мс; счётчики и короба совпали.
Это серверный замер; полный цикл на физическом ТСД требует проверки после установки.

Проданная ВМС, ФБС и отбор ФБО не переключаются на компактный экран.
Откат флага возвращает старый протокол; APK219 совместим с ним.
