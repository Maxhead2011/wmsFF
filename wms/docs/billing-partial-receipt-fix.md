# Частичный приход и загрузка расчётов

Причина ошибки 500 на «Клиенты и расчёты»: полный исторический запрос начислений
загружал финансовые связи и превышал 30-секундную READ ONLY транзакцию.
`BillingSettlementsService.list` теперь читает подробности только за даты услуг,
а `buildSettlements` получает отдельно исторические идентификаторы FBS для проверки
покрытия. История всех филиалов сохранена для проверки, но суммы других филиалов
не показываются. Долг по всем выставленным счетам выбранного филиала и отдельный
аванс не меняют смысл. Флаг нашей WMS и RepeatableRead/READ ONLY сохранены.

Причина полной оплаты вместо частичной: `BillingCashReceiptPanel.toggleInvoice`
переписывал введённую сумму поступления полным остатком отмеченного счёта.
Теперь галочка распределяет только нераспределённую часть введённого поступления
и не меняет его сумму. Без суммы поступления выбор требует сначала её указать.
В «Приход ДС» появилась история поступлений выбранного клиента, включая оплаченные
счета и отменённые ошибочные записи; список для распределения по-прежнему исключает
полностью оплаченные счета. Серверный механизм регистрации оплат не менялся.

Для подтверждённой владельцем ошибки `INV-202609-0007` подготовлена отдельная
коррекция: отмена ошибочной записи 550535,37 с сохранением суммы/истории, новая запись
450000, статус ISSUED, остаток 100535,37. `correct-invoice-partial-receipt.cjs`
проверяет точную исходную запись, блокирует строки и использует общий финансовый
advisory lock через существующий `runBillingMutation`. До/после и причина пишутся
в auditLog; повторный запуск по ключу не создаёт новый платёж. Коррекция не вызывается
автоматически при обновлении программы. Нет уведомлений внешним получателям.

Проверки: регрессии упали до исправлений; API3034/web367 passed (132/2 skipped;
KIZ DB suite требует изолированной БД и исключена). TypeScript API/web,
проверки Node/Python выпуска и коррекции, браузер действующего графа с фиктивным
POST450000, фильтр статуса и кнопка счёта по сданным заявкам сохранены.
На production кандидат READ ONLY за 01–03.10 рассчитан за 2853 мс: 1145 подробных
начислений, 14568 исторических FBS-записей, 3141 счёт, 44 строки клиентов.
Коррекция проверена на настоящей записи с обязательным rollback: данные сохранены.

Только наша WMS, точечная замена двух API-файлов и компонента поступлений в текущем
web-графе. Полная source build не публикуется (source parity false).
Проданная WMS/FFULHAB, складские остатки, тарифы, суммы счетов и их строки не меняются.
