# История нажатий «Скачать стикеры Ozon»

Подготовлено в `fix/ozon-label-click-history`, пока не опубликовано.

После готовности этикеток пользователь нажимает «Скачать стикеры Ozon».
Интерфейс открывает пустую вкладку и вызывает POST
`/ozon-fbo-import/requests/:id/supply/label-download` с supplyId.
Сервер проверяет доступ к клиенту/филиалу, принадлежность поставки и готовность HTTPS-ссылки.
В одной транзакции сохраняются ClientRequestEvent (существующий тип COMMENT)
и AuditLog OZON_LABEL_DOWNLOAD_CLICK. Пользователь берётся из авторизации,
время — из базы. История событий показывает автора, время, поставку и направление.
Ссылка возвращается только после записи события; подписанный URL в историю не попадает.
При ошибке записи пустая вкладка закрывается, пользователь видит ошибку.
Каждое повторное нажатие создаёт отдельное событие.

Событие подтверждает нажатие, а не завершение загрузки или печати.
Прошлые открытия прямой ссылки не восстанавливаются. Запрос генерации этикеток
OZON_LABEL_REQUEST/READY остаётся отдельным действием.

Изменения ограничены OzonAssemblySupplyService/Controller, API-функцией
recordOzonLabelDownload и OzonAssemblySupply. Схема БД, остатки, грузоместа,
отправка в Ozon и проданная WMS не изменяются; действует существующий
WMS_OZON_FBO_IMPORT_ENABLED. История доступна через существующий timeline.

Проверки: серверная регрессия RED (4 ошибки до исправления) / GREEN,
доступ к филиалу, неизвестная поставка, неготовые/небезопасные ссылки,
ошибка сохранения, отсутствие внешних вызовов; веб-проверки API, ожидания
записи перед переходом, блокировки вкладки и ошибки записи.

В ClientRequestTimelineModal время событий/комментариев отображается
с секундами и явной зоной МСК. Реестр administration-internal-api.service
учитывает дополнительный маршрут (59 в группе client-requests).
Эта правка отображения общей истории входит только в кандидат нашей WMS.

Результаты: API 4112 passed / 156 skipped, web 569 passed / 2 skipped.
Отдельный test/kiz-duplicate.integration.spec.ts исключён из итогового общего
запуска: отсутствует выделенная тестовая БД (первый запуск показал ошибку
инициализации Prisma). Существующие пропуски не объявляются проверенными.
Регрессионные проверки нового поведения входят в итоговые полные наборы.
