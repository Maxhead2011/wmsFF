# FBS WB: ожидание сдачи и печать №003361

Подготовлено 25.11.2026 для нашей ВМС. Публикация подтверждается отдельным протоколом выпуска.

№003361 клиента Королёв оставалась IN_WORK, но заказы 6350009767 и 6353411356 имели категорию shipped при WB complete/waiting. Экран показывал их в архиве без подтверждения сдачи. Выбор клиента дополнительно сбрасывался на первого клиента с активными заказами.

`fbsDisplayCategory` оставляет такие незакрытые заявки в текущем списке. Исходная категория не изменяется: повторная сборка не разрешается. DONE сохраняет архив, включая существующее подтверждение закрытой поставки WB. Подтверждённые WB sorted/ready_for_pickup/sold и Ozon delivering/delivered используют прежние правила. Отмена не меняется. Печать, упаковка и ТСД не считаются доказательством сдачи.

`restoreFbsAwaitingForDisplay` добавляет отсутствующие ожидающие заказы из сохранённых связей после ограничения кабинета/филиала, без ограничения давности архивного периода. Затем повторно проверяется филиал. Это только отображение, без записи статуса, ТСД, остатков и биллинга. Включение ограничено существующими WMS_FBS_ACTION_STATUS_ENABLED и WMS_FBS_SAVED_ARCHIVE_ENABLED. Проданная ВМС не публикуется.

Печать из заявки запрашивает сохранённые заказы и для IN_WORK. Переход в FBS передаёт клиента заявки; список активных клиентов не заменяет выбранного. Состав печати ограничен заказами заявки.
