# Автоматические статусы WB для очереди ТСД
Новый модуль wb-linked-status-refresh.ts запускается из MarketplaceConnectionsService.onModuleInit только при WMS_WB_LINKED_STATUS_REFRESH=true. По умолчанию выключен, в аварийном режиме не запускается. Через 5 секунд после запуска и через минуту после окончания каждого прохода читает активные подключения WB и заказы незакрытых заявок страницами по 500. Использует штатный ограничитель запросов WB. Закрытые заявки, удалённые связи, операции с товаром и другие маркетплейсы не затрагивает.

Неполный ответ WB не мешает обработать соседние заказы. Параллельное изменение записи отменяет устаревшую запись статуса. Возврат из доставки в сборку требует проверки новой поставки штатной полной синхронизацией. Ошибка кабинета изолирована; следующий проход повторяет проверку. Тест: wb-linked-status-refresh.spec.ts. После включения зафиксированы запросы фонового обработчика в работающей БД. На 12:00 МСК пять заказов в трёх заявках сверены с WB: пропусков и расхождений нет.
