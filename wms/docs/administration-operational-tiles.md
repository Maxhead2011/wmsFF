# Плитки приёмки и сортировки

Опубликовано 19.10.2026, PR641. Две отдельные плитки в общей сетке администрирования: «Проблемы приёмки» и «Незавершённые сортировки». Доступны ADMIN и OWNER под прежними флагами; демонстрационные аккаунты исключены. Ограниченный администратор получает только операционные инструменты, без API собственника.

Убраны верхняя полоса и пустая карточка сортировки. Контент и его запросы монтируются после выбора плитки. Сортировка использует embedded-режим существующей формы: права, подтверждение, причина и идемпотентная серверная команда не изменены. В приёмке открывается существующий разбор штрихкодов.

Файлы: AdministrationPanel.tsx, AdministrationOperationalTiles.tsx, administration-operational-tiles.css, embedded-режим AdministrationSortingCancellation.tsx. Новый тест AdministrationOperationalTiles.spec.tsx: 6 сценариев ролей, отдельных плиток и отсутствия пустой карточки.

Проверки: web459/2 skipped, API3535/155 skipped (отдельная KIZ integration DB не настроена и исключена), TypeScript web без ошибок. Четыре браузерных сценария на скомпилированном runtime: ADMIN/OWNER × light/dark; общая сетка, открытие каждой плитки, отсутствие пустой карточки и запросов до выбора. Скриншоты просмотрены.
