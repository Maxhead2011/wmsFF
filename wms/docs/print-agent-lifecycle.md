# Постоянная станция Windows и восстановление печати

Версия 2026.10.09.1; только загрузка на wms.logoff.pro. Проданная FFULHAB не обновляется.

Причина ежедневных имён подтверждена пользователем: один компьютер регистрировали
заново с датой. Это не доказательство ежедневного падения процесса. Токен рабочего API
живёт 8 часов; прежний агент уже пытался повторно входить, но рекурсивно и без HTTP-таймаута.
Windows-журнала печатного компьютера у нас нет; причина необходимости ручного запуска
не установлена. Локальный компьютер разработчика из диагностики исключён.

Точки изменения:
- Setup-Agent.ps1 / AgentLifecycle.ps1: прежний config по текущей задаче, постоянный
  stationId, установка в LocalAppData, явный интерактивный пользователь, запуск при входе,
  отсутствие лимита времени и остановки на батарее, IgnoreNew и mutex.
- WmsApi.ps1: HTTP 30с, максимум одна повторная авторизация на запрос.
- JobJournal.ps1: атомарный started/result/acknowledged на диске до/после передачи
  драйверу. Потеря ACK повторяет только результат; неизвестный исход запрещает автоперепечатку.
- Основной агент и PrintSeries.ps1: сохранены опубликованные FBS/relabel/generic/series.
  Одиночный рендер и многостраничный PrintDocument совпадают с публичным PR505.
- Build-Package.ps1: восемь публичных файлов с BOM для PowerShell5; никаких конфигураций.
  Исторический Python overlay намеренно закрыт, чтобы не собрать архив без нового журнала.

Опрос здоровой очереди остался 2с. Число запросов для 110 FBS заданий: 330 до и после.
Тест с подменённым принтером: медиана обработки 1.24→39.90мс, p95 2.10→50.70мс.
Разница — синхронное сохранение результата на диск. Это не замер физического TSC или сети.
В серияx прежний единый документ, без пауз между страницами. Физический драйвер может
зависнуть внутри Print(); принудительного убийства/автоперепечатки такого документа нет.

Проверки: 24 сценария на распакованном архиве (PowerShell5, fake HTTP и spooler),
отдельный старый регрессионный сценарий lost ACK падает на публичном агенте и проходит
на новом; setup SelfTest; пакет без секретов; точное сравнение кода вывода этикеток.
Общие тесты актуальной базы PR529: API3258/web412;138/2 skipped,
отдельные KIZ integration исключены (не настроена изолированная БД).
Локальное подключение к реальному принтеру и установка на станции не выполнялись.

Для первого обновления завершить печать и остановить старую задачу, распаковать архив,
запустить Install-Agent.cmd под обычной учётной записью печатного компьютера.
Повышение прав допустимо для той же учётной записи. ID0910 переносится из прежнего config;
вручную дату не вводить. Будущие обновления завершают текущий цикл через stop.request.
Если агент занят и не завершился, файлы не заменяются. Не удалять journal при обновлениях.

Диагностика локальная: agent.log, status.json с версией/временем/пользователем/состоянием.
config.json содержит пароль и не должен передаваться в поддержку. Серверное API не менялось.
Выпуск заменяет только downloads/LOGOFF-FBS-Print-Agent.zip в образе web;
API, APK, настройки, БД и остальной веб-граф остаются прежними.
