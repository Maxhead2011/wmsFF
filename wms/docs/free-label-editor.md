# Свободная этикетка — опубликовано PR1064

Ветка `feature/free-label-editor`, предполагаемая база PR: `feature/la_panthera`.

Новый пункт в печати доступен только нашей установке и сохраняет проверку `print:write` родительского экрана. Проданная установка не получает новый пункт. Старые формы и агент печати не меняются.

## Текст и счётчики

Размеры берутся из действующих шаблонов `/print/templates`. Независимые поля: текст с переносами, шрифт, размер в пунктах, жирность, курсив, выравнивание, поворот 0/90/180/270, координаты и размеры в миллиметрах, перетаскивание. Счётчик имеет собственный префикс, начало, шаг и число цифр; количество этикеток задаёт длину серии. Макеты сохраняются/открываются JSON. Можно указать установленный шрифт или загрузить TTF/OTF/WOFF. Загруженные шрифты остаются в текущем сеансе; при повторном открытии макета требуется тот же файл шрифта.

Предпросмотр и печать используют один растр 300 dpi. Переполнение текстового поля блокирует подготовку. Не выполняется ни приход, ни списание, ни изменение статуса заявки. До 30 полей и 100 этикеток; размеры от 10 до 200 мм.

## Файл

PDF, PNG, JPG, WebP до 40 МБ. PDF до 100 страниц; выбор диапазонов `1,3-5`, удаление повторов. Вписывание всей страницы с сохранением пропорций, без обрезки. Содержимое обрабатывается локально в браузере, без загрузки на сервер. PDF.js и worker включены в сборку, внешний CDN не используется. Исполнение выражений PDF отключено.

Оба режима сначала создают окно со всеми подготовленными страницами. Только отдельная кнопка открывает системный диалог выбора принтера (включая сохранение PDF). Ни агент, ни физический принтер автоматически не вызываются. Масштаб 100%, без полей; копии в диалоге 1, так как количество уже включено в подготовленные страницы.

## Silent print agent

Both modes also offer «Печать через агент»: select client and online printer bound to the exact label size, then explicitly send all PNG pages as one existing print-series job. No automatic printing or stock/status/billing operations. Unknown network responses retain the same request UUID; a known failed job requires queue inspection instead of blind retry. Backend limits: integer sizes20–150mm and8MB total; up to100 pages in this editor. Existing browser printer selection is retained. Tests: freeLabelAgent.spec.ts (3), web668 passed/2 skipped, TypeScript and full-app candidate browser with intercepted queue writes. Physical printer not tested.
