# Тихое обновление: сохранённая позиция FBO

На HT330 с версией267 APK270 уже находился в cache, очередь операций была пустой. Сохранённая позиция FBO содержала barcode; IdleUpdateGuard ошибочно приравнивал её к неподтверждённой команде и бесконечно откладывал установку.

Реальный ключ команды, очередь outbox, незавершённая приёмка и повреждённое состояние по-прежнему блокируют установку. Экран обязан быть безопасным; активная сборка не прерывается. Сообщения различают загрузку и ожидание безопасной установки.

// TEST: сохранённый barcode/КИЗ разрешает обновление без изменения состояния; добавленная неподтверждённая команда блокирует; повреждённый JSON блокирует. 365 Android release tests passed. Подписанный APK проверен на эмуляторе с настоящим Android JSON/runtime.

Изменяется только канал server-choice нашей WMS (271), обычный канал остаётся270. Сборка — минимальный overlay на опубликованный APK270: один метод guard, два status-callback и версия. Ресурсы и прочие методы сохраняются. Проданная WMS не публикуется.

Для уже заблокированной версии267 требуется однократный диагностический запуск штатного PackageInstaller после проверки пустой очереди и сохранённых позиций; исправленный механизм не может исполниться до установки нового пакета. Проверка физического устройства и публикации будет записана отдельно.
