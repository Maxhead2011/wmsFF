# FBO Ozon: единая сборка из файла клиента

Связь с существующей поставкой и передача проверенных коробов добавлены следующим этапом: [сценарий интеграции](ozon-assembly-supply-link.md). Ниже сохранено описание первого выпуска импорта.

Подготовлено в `feature/ozon-fbo-client-file`; целевая ветка PR — `feature/wb-print-check`. Опубликовано PR516, APK220.

## Структура

Один Excel создаёт одну OUTBOUND-заявку с общей потребностью по SKU. В `OzonFboShipment.directions` сохраняется распределение SKU по направлениям. Количества берутся из файла клиента, а не из кабинета Ozon. Повтор того же распределения, даты и места отгрузки возвращает существующую заявку.

Отбор общий, поштучный, через существующий FBO-процесс. При открытии упаковочного короба выбирается направление. Сервер проверяет его квоту по SKU перед перемещением товара. Завершение требует полного распределения и проверки коробов. Неотобранный остаток остаётся AVAILABLE. Перенос исходного короба целиком, частичное закрытие потребности и ручное добавление сверх файла в этом режиме отключены. WB-выгрузки для Ozon не используются; отправка данных в кабинет Ozon не реализована этой задачей.

## Изоляция и выпуск

Флаг `WMS_OZON_FBO_IMPORT_ENABLED=true` включать только на нашей WMS с действующим `WMS_FBO_TWO_STAGE_ENABLED`. На проданной WMS флаг отсутствует. После создания Ozon-заявок нельзя использовать выключение флага как откат: сначала требуется согласовать судьбу активных сборок.

Изменены импорт клиентских заявок, метаданные Prisma, FBO-сервис, WMS-панель сборки и экран Android. Общие WB-сценарии покрыты регрессионными тестами.

Исходники не равны production. API-кандидат материализован из `2026-10-09-menu-reads`, затем дополнен `scripts/build-ozon-customer-fbo.cjs`; точный список десяти runtime-файлов прошёл `release_baseline.py check-candidate`. Перед выпуском снова проверить свежие image ID. Миграция аддитивная: новая таблица и nullable-направление короба. Production Prisma-клиент генерировать из актуальной серверной схемы с добавлением этих полей, не заменять серверную схему полной локальной копией. Web-кандидат и APK220 опубликованы; запись выпуска: `releases/ozon-customer-20261009.json`.
