# Разрешение администратора для отменённого заказа

Сборка №1317, заказ WB 5852071983: КИЗ возвращён в доступный остаток,
но отменённый заказ 5615884548 из принятой поставки автоматически требовал
переклейку. Новое правило отправляет такой случай на решение администратора.
Неизвестный статус погашения допускается по явно подтверждённому правилу владельца.
Продажа, RETIRED/WRITTEN_OFF и defect продолжают требовать переклейку.

Флаг `WMS_KIZ_CANCELLED_ADMIN_REUSE_ENABLED` по умолчанию выключен. Только наша
WMS; проданную WMS не публиковать и флаг там не включать.

Изменения: `decideKizReuse`, оба способа решения `KizReviewQueue.decide/decideUnit`,
новый `releaseCancelledBindings`. Администратор должен подтвердить фактическую
единицу в доступном коробе. Прежняя завершённая привязка освобождается только при
свежем подтверждении отмены всех прежних заказов, закрытой заявке и независимой
истории отгрузки. Полный снимок прежней привязки и доказательства сохраняются в
AuditLog в той же транзакции; история отгрузки, остатки и внешние заказы не меняются.
Повторный скан заново проверяет WB; последующее подтверждение продажи отзывает разрешение.
