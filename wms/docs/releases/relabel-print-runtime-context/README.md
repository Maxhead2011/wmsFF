# Переклейка FBS и фиксированная пятёрка Лукина

Кандидат для нашей WMS, 25.09.2026. База API:
`sha256:b46825792d5c1f5be44e52edd3b28248107daedd939548ce5113bd782c701bd9`.

## Причина

В runtime отсутствовали уже имеющиеся в исходниках `getFbsTsdRelabelPrintContext`,
обработка `TSD_RELABEL` в claim/finish и вызовы фильтра пяти заявок. Поиск станции
обрывался до постановки печати. Старый claim строил сортировочную этикетку вместо
второго экземпляра товарной. Android 212 дополнительно блокировал сканирование
до ACK, хотя этикетку можно напечатать через WMS/NiceLabel.

## Изменение

- `MainActivity.renderFbsAssemblyScreen/submitFbsScan`: скан и автофокус не зависят
  от подтверждения печати. Статус печати остаётся реальным; проверка целевого ШК
  сервером сохранена. Отдельный сценарий меню переклейки и обычная печать не меняются.
- LOGOFF APK 213; версии остальных вариантов не меняются.
- `patch_runtime.py` восстанавливает только перечисленные фрагменты из текущего
  исходника. Начальный SHA обязателен. Новые серверные обработчики отгрузки,
  биллинга, автостатусов, маршрутов и Ozon сохраняются.
- `listFbsTsdRequests/getNextFbsTsdAssemblyUnlocked`: закреплённые пять старейших
  заявок Лукина; следующий набор после завершения всего текущего. ADMIN/OWNER и
  другие клиенты без лимита. Уже начатое сканированием задание не теряется.

## Проверки

- До исправления: Android реальный экран отключает поле; runtime возвращает 7
  вместо 5, не имеет print context, строит неверную пару, допускает неверный путь ACK.
- После: 26 проверок runtime, включая capability, Ozon counter, WB sequential pick
  и текстовый экран без загрузки стикера.
- API: 2754 passed, 94 skipped; отдельно исключён DB-dependent
  `kiz-duplicate.integration.spec.ts`, тестовой БД нет. Пропуски не считаются успехом.
- Android LOGOFF: 216; FFULLHAB: 216, все прошли; release APK собран.
- Подпись APK совпала с опубликованной 212; содержимое после подписания неизменно.
- Проверка baseline: меняется ровно один runtime-файл из 533.
- Веб-кандидат: только APK, метаданные обновления и именованная копия APK.

Проданная WMS не публикуется. Общие функции MarketplaceConnectionsService затронуты
только в образе нашей WMS; полный локальный dist не используется.
`sourceParityVerified=false` остаётся: этот ремонт не сводит все исторические различия.
Фактическую физическую печать нужно подтвердить на станции; тесты её не имитируют.
