# Окна сборок Ozon и Lamoda

В нашей ВМС кнопки «Открыть сборку» и «Поставка и грузоместа Ozon» открывают
окно поверх списка, по образцу FBO WB «Онлайн». Список не прокручивается вниз.
Таймер Ozon, данные клиента и операции сохраняются. Закрытие загрузки отменяет
показ её позднего ответа; закрытие готовой сборки использует прежнюю защиту
от незавершённой операции.

Lamoda FBO показывает строки с колонками «Заявка», «Состав», «Срок / статус»,
«Склад», «Действия». Клиент находится в составе. Количество подписано **«По плану»**:
API списка возвращает исходный план, а фактический отбор и упаковка доступны
в открытой сборке. Черновики сохраняют проверку соответствий/остатков;
созданные заявки — открытие и разрешённое сервером удаление. Выбор клиента и
кабинета сохраняет прежнюю область доступа. Лимит существующего overview API
в 100 планов этим интерфейсным изменением не расширяется.

В окне Lamoda вместе находятся выполнение сборки и оформление поставки.
Свернуть/развернуть окно можно в теме «Пантера». При обычном обновлении строки
списка сохраняются до ответа; при смене клиента/кабинета/филиала очищаются.

## Файлы и границы

- `OzonCustomerWorkspace.tsx`: окно — сосед CSS-контейнера, выбор заявки,
  защита от поздних ответов и сохранение списка при обновлении.
- `LamodaPanel.tsx`, `LamodaAssemblyList.tsx`, `lamoda-assembly-list.css`:
  таблица и сборка с оформлением в одном окне только в operational FBO.
- `FboWorkspaceModal.tsx`/CSS: оболочка окна с восстановлением фокуса;
  сборка сохраняет собственные кнопки закрытия и busy guard.
- `PantheraWorkspaces.tsx`: распознавание заголовка вложенной сборки для
  существующего сворачивания и перенос его кнопки при замене заголовка
  загрузки. Состояние свёрнутого окна сохраняется. Общий механизм отбора
  не меняется.

API, схема БД, остатки, резервы, APK и проданная ВМС не изменяются. Старые
Lamoda FBS/обслуживание кабинета и legacy Ozon сохраняют прежний вид.
Не добавлены обработчики закрытия по фону/Escape, обходящие busy guard.

## Проверка и выпуск

Регрессия Ozon воспроизведена на опубликованном PR759: сборка открывается внизу
и не имеет модальной оболочки. Исходный тест Lamoda воспроизвёл старую сетку.
Добавлены проверки оболочки, плановых количеств, колонок и прежних действий.
Проверяются реальные опубликованные JS-модули с синтетическими API-ответами:
положение окна после прокрутки, закрытие/сворачивание, поздние ответы, права,
создание из черновика и совместное отображение сборки/оформления.

Публикация — только через PR из `fix/fbo-modal-rows` в `feature/wb-print-check`.
База — PR759, `2026-10-29-ozon-all-clients`, `sourceParityVerified=false`.
Ровно 5 web-файлов: index, существующий core с точечной правкой сворачивания,
два host-модуля с заменой только функций workspace, CSS. Общий React-граф,
опубликованные функции отбора, импорта и отправки сохраняются. Скрипты выпуска
проверяют исходные образы, hashes кандидата, merged PR и browser proof.

Откат: `logoff-web:before-fbo-modal-rows-20261029`; бизнес-данные не затрагиваются.
