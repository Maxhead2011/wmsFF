# SOS WB2: печать после отбора по заявке

## Правило выбора меню

Настройка клиента «Все товары с КИЗ» (`client.receipt-kiz-required.v1`) включена — сохраняется прежнее меню КИЗ. Выключена или не задана — режим «По заявке» показывает уже отобранные немаркированные заказы WB/Ozon. Дополнительно проверяется маркировка конкретного задания. Имена клиентов не зашиты в код: поддерживаются в том числе Королёв, Королёва и Баландин.

## Работа сотрудника

1. Обновить SOS WB2 до APK9, выбрать рабочий сервер и войти.
2. Открыть «По заявке», выбрать заявку и доступную станцию печати.
3. Повторно сканировать товарный ШК. Отправляется официальный стикер выбранного заказа и существующая сортировочная этикетка.
4. «Передано на печать» означает очередь. После обновления списка количество напечатанных увеличивается только по ответу агента.
5. Повторная печать — отдельное подтверждаемое действие. При сетевой ошибке повторяется прежний UUID, а не создаётся ещё одно задание.

Печать не выполняет отбор, списание, передачу заказа маркетплейсу или начисление услуг. Для Ozon требуется завершённая передача результата отбора. Многостраничный официальный стикер Ozon блокируется с предложением использовать скачивание в WMS: частичная печать грузомест недопустима.

## Реализация и границы

- `sos-post-pick.ts`: выборка по филиалу/клиенту, политика КИЗ, точная связь заказа с заявкой, очередь `SOS_POST_PICK`, аудит, UUID и блокировка конкурентной отправки.
- `marketplace-connections.service.ts`: чтение официальных этикеток, атомарный захват очереди, исключение из автоматического списания при ACK и восстановлении.
- Controller: два маршрута `fbs/sos/post-pick/requests` и `fbs/sos/post-pick/print`; реестр API обновлён.
- Android: список заявок, ШК, станция, подтверждённый повтор, сохранение неопределённого сетевого результата.
- Действующий флаг `WMS_FBS_UNMARKED_PAIRED_LABELS_ENABLED` ограничивает серверную функцию нашей WMS. Среда и проданная WMS не меняются.
