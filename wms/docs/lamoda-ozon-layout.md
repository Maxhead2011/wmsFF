# Lamoda FBO: компоновка как у Ozon

Опубликовано 28.10.2026 через PR723 из `fix/lamoda-ozon-layout` в `feature/wb-print-check`. Проверка публичного сайта: 43 сценария, ошибок JavaScript нет. Остальные контейнеры сохранились без перезапуска.

## Изменения и влияние

- `LamodaPanel.tsx`: только operational FBO показывает компактный заголовок, строку клиента/кабинета/филиала и кнопку создания. Формы файла и существующей поставки раскрываются по кнопке, переключаются отдельно. Список занимает всю ширину; вкладки активных/завершённых, выбор 4/5/6 колонок, номер и статус на карточке. На узком экране число колонок автоматически уменьшается. После создания сохраняется встроенное выполнение из PR721.
- `lamoda.css`: все новые правила ограничены `.lamoda-ozon-layout`; выбранная вкладка различима в Panthera, карточки имеют подложку. Старые FBS/обслуживание и default-off режим не получают новую компоновку.
- `LamodaPanel.test.tsx`, `scripts/tests/marketplace-workspaces-browser.cjs`: регрессия компактной страницы и прежних границ доступа.
- `scripts/releases/lamoda-layout-20261028`: точечная сборка и браузерная проверка фактического runtime. Выпуск меняет только `index.html` и два новых JS/CSS ресурса поверх проверенного PR721.

API, резервы, логика сборки, схема, APK236 и проданная ВМС не меняются. Лимит списка из API по-прежнему 100 планов. Не добавляются операции с поставками Lamoda или отправка остатков. Выбор филиала сохраняет прежний смысл — филиал создания плана; это не новый фильтр истории.
