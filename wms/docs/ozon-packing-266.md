# Упаковка Ozon FBO и ТСД 266

Зона берётся из placement_zone состава конкретной поставки. При упаковке микса WMS сверяет зоны до движения товара и КИЗ. Для старой поставки без зон обновите состав или упакуйте по одному SKU. При выборе короба по товару рекомендации исключают несовместимые короба.

При скачивании и печати стикеров WMS связывает каждую страницу по cargo_id с физическим коробом и добавляет его код под точкой сдачи. Флаги нашей WMS — WMS_OZON_BOX_ZONES_ENABLED и WMS_OZON_BOX_LABEL_ENABLED.

В канале с выбором сервера LOGOFF 266 включает озвучку упаковки Ozon и персональные записи Элеоноры. Пакет подготовлен поверх версии 265 с сохранением кода очереди и приёмки. Установка и звук на физическом ТСД проверяются отдельно.
