# Онлайн-выполнение: история и скрытые окна

Точечный выпуск для нашей ВМС, под существующим WMS_MENU_READS_ENABLED.
Браузер запрашивает view=summary; полная история не передаётся, её счётчик сохранён.
По раскрытию view=history возвращает страницы по 100 единиц. Ошибку можно повторить;
закрытие или переход на другую страницу исключает устаревший ответ.
Скрытые/свёрнутые окна не опрашивают сервер, восстановление запускает свежий запрос.
Каталог ФБС читает две независимые проекции параллельно, без кэша готовых остатков.
Старые ТСД без query-параметра получают полный ответ. Записи, резервирование,
маршруты, КИЗы и сканирования не меняются. История пока формируется сервером
в составе полного плана: сокращены передача и DOM, не вся серверная работа.

Проверки: online-plan-view.spec.ts, menu-read-catalog-parallel.spec.ts,
online-window-runtime.cjs, online-window-browser.cjs. Браузерный тест падает
на предыдущем графе: закрытая история уже содержит 251 строку.
Полные тесты и TypeScript обязательны; актуальный runtime собирается guarded delta,
поскольку sourceParityVerified=false. Проданная ВМС не обновляется.
