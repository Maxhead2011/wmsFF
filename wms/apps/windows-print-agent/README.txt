LOGOFF FBS PRINT AGENT

1. Установите штатный Windows-драйвер принтера.
2. Запустите Install-Agent.cmd от имени администратора.
3. Введите логин и пароль WMS (в том числе «Склад»), выберите принтер и его модель.
4. Нажмите «Подключить и запустить».

Станция создаётся в WMS автоматически. config.json заполнять вручную не требуется.

Агент печатает две этикетки без диалоговых окон и сообщает результат в WMS.

Редакция 2026-09-13: кириллический вход и единая сортировочная наклейка.
Права администратора Windows для установки не означают, что нужен администратор WMS.
Используйте свою учётную запись WMS с разрешением печати и нужным филиалом.
Сортировочную наклейку формирует сервер — изображение совпадает с прямой печатью в WMS.
Перед установкой этой версии необходимо обновить API и веб WMS с поддержкой sortingLabel.
Перед обновлением остановите задачу «LOGOFF FBS Print Agent» в Планировщике заданий Windows.
Распакуйте новый агент в отдельную папку и снова выполните «Подключить и запустить».
Установщик заменит зарегистрированную задачу. Не передавайте config.json другим людям.
Для стандартной наклейки выбирайте бумагу 58×40 мм; другой размер изменяет физический масштаб.
