LOGOFF PRINT AGENT — 2026.10.09.1

Обновление существующей станции (например, 0910)
1. Дождитесь завершения печати. При первом переходе со старой версии остановите
   задачу «LOGOFF FBS Print Agent» в Планировщике заданий Windows.
2. Распакуйте ВСЕ файлы архива в отдельную папку и запустите Install-Agent.cmd.
   Установщик найдёт config.json по прежней задаче и сохранит станцию, пароль,
   принтер и размеры этикетки. Новое название по дате вводить не нужно.
3. Нажмите START / UPDATE SAVED STATION. Установка выполняется в постоянную папку
   %LOCALAPPDATA%\LOGOFF\PrintAgent. Исходную папку распаковки можно убрать.
4. Дождитесь сообщения о подключении. В ТСД остаётся та же станция.

Первое подключение нового компьютера
Установите Windows-драйвер принтера. Запустите Install-Agent.cmd, введите логин
и пароль WMS, выберите принтер, модель и постоянное имя станции.
Работайте под той же учётной записью Windows, под которой сотрудники входят утром.
При необходимости разрешено повышение прав ЭТОЙ учётной записи. Запуск от другого
администратора установщик отклонит: его принтеры и автозапуск относятся к другому профилю.

Ежедневная работа
Агент запускается автоматически при входе этого пользователя в Windows.
Каждый день запускать установщик, менять имя и выдавать права администратора не нужно.
Повторное открытие той же версии оставляет работающий агент запущенным.
При потере сети агент восстанавливает связь самостоятельно. Интернет нужен только
компьютеру печати; задания с ТСД и удалённой ВМС по-прежнему идут через сервер.
Компьютер должен быть включён и пользователь должен войти в Windows.

Печать
ФБС: прежняя пара этикеток; переклейка: две одинаковые целевые этикетки.
Обычные ШК: прежнее количество копий. Серия: один документ Windows со всеми страницами.
Нормальный опрос очереди — раз в две секунды. При сбоях повторы ограничены паузой до 30с.
Результат сохраняется в journal до отправки серверу. Потеря ответа не печатает его снова.
Если процесс прервался при передаче драйверу, проверьте фактические этикетки перед
ручным новым заданием. Не удаляйте journal и не запускайте старую версию параллельно.

Диагностика
В постоянной папке: status.json (версия, пользователь, время запуска, состояние)
и agent.log (ошибки). config.json содержит учётные данные — не пересылайте его.
Диагностика пока локальная; сервер не получает журнал Windows автоматически.
Зависание драйвера внутри Windows требует отдельной диагностики; принудительный
перезапуск во время печати может оставить неопределённый результат.
