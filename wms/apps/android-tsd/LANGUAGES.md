# Язык ТСД и русский мониторинг

Изменение включено только для flavor `logoff`. Экран входа предлагает русский,
узбекский (латиница) и английский. Выбор хранится в существующих настройках ТСД.
Смена языка сохраняет заполненные поля входа. Другие варианты приложения сохраняют
прежнее поведение.

`TsdUi` переводит только отображение TextView, кнопок, подсказок и диалогов.
В рабочих состояниях, запросах, очереди сканов и мониторинге остаётся исходный
русский текст. Значения EditText не переводятся. КИЗ, ШК и параметры шаблонов
сохраняются посимвольно. Для отдельного поля с данными используйте `TsdUi.data`.
Произвольный текст сотрудника не переводится автоматически.

Словарь `app/src/main/assets/tsd-translations.tsv`: русский, узбекский, английский.
Символы табуляции разделяют столбцы. Внутри текста используются `\n`, `\t`, `\\`
и `\s` (значимый пробел в конце строки). В `tsd-templates.tsv` перечислены формы
составных подписей. `{0}` обозначает очередной параметр, который переводчик не
меняет. Для серверной фразы со сложной грамматикой можно хранить полный шаблон
с параметрами сразу в словаре. Число и порядок параметров должны совпадать.
Неизвестные сообщения сохраняются в оригинале: переводчик не подменяет смысл
неизвестной ошибки предположением.

При захвате для мониторинга на главном потоке временно отображаются русские
подписи основного окна и открытых диалогов нашего приложения. Затем рисуется
изображение и в `finally` возвращается исходное отображение. Между этими действиями
нет передачи управления UI. Поля ввода, выделение, фокус и сохранённый язык не
меняются. Внешние окна Android, клавиатура и другие приложения не захватываются.
Сведения `uiLanguage` и `screenshotLanguage` описывают язык сотрудника и снимка.

Проверки: `TsdTextCatalogTest`, `TsdSnapshotTransactionTest`, `TsdUiTest`,
`TsdRussianScreenshotTest`. Последний рисует настоящие bitmap через Robolectric,
сравнивает русский снимок с русским экраном попиксельно и проверяет восстановление
изображения сотрудника. Примеры сохраняются в `app/build/reports/tsd-language-screenshots`.
Для проверки всех вариантов: `gradle :app:test :app:assembleLogoffRelease`.

Публиковать следует APK на базе действующего APK 176, сохраняя поиск КИЗ,
персональное приветствие, физический отбор FBS и двухэтапный FBO. Интеграционная
Git-ветка не содержит все изменения исходников действующего APK; нельзя заменять
им действующее приложение без проверки состава.

UI-привязки двух экранов из действующего APK сохранены в
`scripts/tsd-language-live-screens.patch`. После переноса изменений PR на исходники
APK 176 примените этот патч с `git apply --unidiff-zero` (сначала `--check`).
В нём только подключение отображения и захвата диалога, без изменений бизнес-логики.

Проверено: API — 2681 тест; web — 206; Android репозитория — 108 тестов в каждом
из шести вариантов; APK-кандидат с сохранёнными рабочими функциями — 115 тестов
в каждом из шести вариантов. Сборка release и lint прошли. В байткоде APK отдельно
проверены вызовы русского снимка, перевода виджетов, FBO, поиска КИЗ и отбора Ozon.
