# LOGOFF · Учёт времени — Android-планшет

Пилотная сборка отдельного приложения, Android 11+ (API 30). Не заменяет приложение ТСД.

**Серверный API планшетов пока отсутствует в опубликованной WMS.** Этот проект — клиент и контракт интеграции; установка APK сама по себе не включает запись смен. Кнопка регистрации честно показывает ошибку при отсутствии API. Демо-сотрудников и имитации успешного учёта нет.

## Реализовано

- Подключение одноразовым кодом, токен в хранилище с ключом Android Keystore.
- Сотрудники своего филиала, поиск, приход/уход, несколько интервалов, фото с фронтальной камеры и подтверждение.
- Полные даты и время съёмки, без обрезания ночных смен.
- Форма погрузки/разгрузки: начало, дробное количество паллет, участники, комментарий.
- Устойчивая Room-очередь и приватные фотографии; UUID для повторной отправки; фоновые повторы WorkManager.
- Все финансовые расчёты остаются на сервере. В приложение не запрашиваются ставки, телефоны и банковские реквизиты.
- Состояние очереди, отсутствие разрушительных миграций, запрет подмены филиала при отправке.

## Сборка

Требуются JDK17 и Android SDK35. Gradle Wrapper включён.

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Это установочная тестовая сборка с debug-подписью, не промышленный канал обновления. Перед внедрением нужны отдельный постоянный ключ подписи, серверная интеграция и проверка на двух планшетах. Не удалять установленное приложение с неотправленной очередью; обновлять APK с тем же package ID и ключом.

## Дальнейшая интеграция

См. [API-CONTRACT.md](API-CONTRACT.md). Добавить серверный модуль в существующую WMS, административное подключение/отзыв устройств, закрытое хранение фото, просмотр и разрешение спорных отметок в ФОТ. Проверки прав, единственного открытого интервала и расчётов выполнять на сервере. В этом изменении API, БД, production и проданная WMS не изменены.

Режим системного киоска, удалённое управление устройствами и автоматическое удаление фото пока не включены. Приложение не запрашивает права launcher/device owner или фоновую камеру. До подключения реальных работников согласовать срок хранения фотографий и испытать восстановление после сбоя и работу камеры на конкретных моделях.
