# LOGOFF · Учёт времени — Android-планшет

Пилотная сборка отдельного приложения, Android 8+ (API 26). Не заменяет приложение ТСД.

**Серверный API и экран управления опубликованы на нашей WMS через PR343, 27.09.2026.** Подключение: ФОТ → Настройки → Планшеты и отметки → выбрать филиал → выдать одноразовый код (15 минут). В приложении указать название планшета и код. Пароль сотрудника не требуется. Демо-сотрудников и имитации успешного учёта нет.

## Реализовано

- Подключение одноразовым кодом, токен в хранилище с ключом Android Keystore.
- Сотрудники своего филиала, поиск, несколько интервалов. Нажатие прихода/ухода автоматически делает снимок фронтальной камерой, без отдельного экрана и подтверждения фото.
- Полные даты и время съёмки, без обрезания ночных смен.
- «Обед» / «Вернулся»: фактический интервал перерыва вычитается сервером из оплачиваемого времени. Статус обеда виден и при отсутствии связи.
- Форма погрузки/разгрузки: начало, четыре отдельные строки — палеты, короба, мешки, рулоны; участники и комментарий. Палеты допускают дробное количество, остальные единицы — только целое.
- 1 палета = 16 коробов = 5 мешков = 30 рулонов. На сервере используется ставка 500 ₽ за палетный эквивалент. Один объём нельзя одновременно вводить в нескольких единицах.
- Устойчивая Room-очередь и приватные фотографии; UUID для повторной отправки; фоновые повторы WorkManager.
- Все финансовые расчёты остаются на сервере. В приложение не запрашиваются ставки, телефоны и банковские реквизиты.
- Состояние очереди, отсутствие разрушительных миграций, запрет подмены филиала при отправке.

## Сборка

Требуются JDK17 и Android SDK35. Gradle Wrapper включён.

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK для тестов: `app/build/outputs/apk/debug/app-debug.apk`. Он содержит тестовую Activity Compose и не предназначен для распространения. Для установки собирать `:app:assembleRelease :app:lintRelease`, подписывать `app/build/outputs/apk/release/app-release-unsigned.apk` существующим ключом приложения и проверять `scripts/verify_apk.py`. Не удалять установленное приложение с неотправленной очередью; обновлять APK с тем же package ID и ключом. Пилот 0.3.0 подписан debug-ключом: для совместимого обновления 0.3.1 сохранена эта подпись; перевод на промышленный канал требует отдельной миграции ключа.

## Доработка 0.3.1 · 06.10.2026

При фотоотметке список сотрудников скрыт до завершения или отмены. Если выбранный сотрудник больше недоступен, требуется явный возврат к списку. Регрессионные Compose-тесты воспроизводят прежнее наложение экранов и проверяют исправление. Дополнительно проверяется ввод четырёх видов груза и направления работы через настоящую форму.

У количеств включена цифровая клавиатура; обед выделен цветом и пояснением об исключении из оплаты. Версия видна на главном экране. Регистрация, схема Room и очередь не меняются. Сервер и проданная WMS в эту доработку не входят. Автоматические тесты не заменяют проверку камеры на физическом планшете.

## Дальнейшая интеграция

См. [API-CONTRACT.md](API-CONTRACT.md). Серверный модуль расположен в `apps/api/src/modules/expenses/attendance-device.service.ts`. В ФОТ → Настройки добавлены подключение/отзыв устройств, запрос фото, закрытый просмотр и разрешение спорных отметок. Проверки филиала и единственного открытого интервала выполняются на сервере. Перед публикацией нужны миграция `20260927010000_attendance_devices` и флаги `WMS_PAYROLL_ATTENDANCE_ENABLED=true`, `WMS_ATTENDANCE_DEVICE_ENABLED=true` только на нашей WMS. Публиковать через актуальную runtime-базу и `release_baseline.py`, не полной локальной сборкой. Наш production обновлён через PR343; проданная WMS не изменена.

Фото хранятся в приватной папке 35 дней. Очистка запускается при старте и фоновым заданием без требования сети; Android может отложить запуск, а выключенный планшет удалит просроченное при следующем запуске. Табель и очередь при очистке не удаляются. Просроченное фото не передаётся даже до физического удаления. Режим системного киоска и удалённое управление устройствами пока не включены. Приложение не запрашивает права launcher/device owner или фоновую камеру. До подключения реальных работников испытать восстановление после сбоя и работу камеры на конкретных моделях.

Рядом с кнопками отметки — уведомление о фотофиксации; системное разрешение и индикатор камеры Android сохраняются. Камера привязана к активному экрану и освобождается после снимка.

**Сервер проверен на локальном PostgreSQL и на серверной БД с полным откатом тестовых записей; клиент — автоматическими тестами.** Физическая камера двух планшетов пока не проверена. Запрошенные фото на сервере также перестают быть доступны через 35 дней от отметки и очищаются, сами отметки сохраняются.
