# Проверяемый снимок our-wms-2026-09-25

Это фактически опубликованные файлы, а не предложение обновить production.
Область и ограничения — в [паспорте](../../../docs/current-production.md).

- `api-runtime.tar.gz`: содержимое `apps/api/dist`, точные исполняемые JS-файлы.
- `api-source-reference.tar.gz`: активные TypeScript-файлы, схемы/миграции,
  package.json и tsconfig из контейнера. Не гарантированная сборочная база.
- `web-runtime.tar.gz`: `index.html` и `assets` действующего веб-контейнера.
- `logoff-tsd-212.apk`: опубликованный APK, хеш совпал с download-метаданными.
- `manifest.json`: версии, SHA-256 архивов и каждого файла внутри, булевы флаги.
- `divergence.json`: расхождения относительно Git/локальной сборки на момент снимка.

Из `wms/`: `python scripts/release_baseline.py verify`.
Не выполнять файлы из reference и не применять миграции только потому, что они
есть в снимке. Зависимости, конфигурация с секретами, данные и образы Docker
не входят в эти архивы. Восстановление исполняемых файлов не восстанавливает сервер целиком.
